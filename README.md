## 📚 About The Project

**Language App** is a modern web application for interactive language learning with AI, a responsive interface, and a variety of engaging exercises.  
Learn, translate, take quizzes, describe images, write essays — all in one place!

## ✨ Features

- 🎯 **Personalized exercises:** translation, flashcards, quizzes, essays, image descriptions
- 🌐 **Multilingual interface**
- 📱 **Responsive design** for mobile and desktop
- 🔒 **Secure authentication** and profile management
- 🤖 **AI-powered hints** and content generation
- 🧩 **Modern UI** with Radix UI and TailwindCSS


---

## 🌐 Available Languages

- **Interface languages:** English, Ukrainian, German, French, Spanish, Polish, Arabic, Czech
- **You can learn:** **any language** — just select your target language or enter it manually!

> The list above includes all supported interface languages.  
> You can practice and generate exercises for any language you want to learn.

## 🚦 Usage

- Open Language App in your browser and register a new account or log in.
- Select the language you want to learn and specify your current level.
- Add your interests and goals to receive personalized exercises.
- Use different exercise types: translation, flashcards, quizzes, essays, and image descriptions.
- Check your answers and get AI explanations and hints.
- Manage your profile, update your settings.
- Add new languages to learn at any time.

> **Tip:**  
> For the best experience, use a modern browser and a device with a large screen.
